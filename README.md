## GitHub Pages Configuration

To view the presentation, you need to configure your GitHub Pages to serve from the `/docs` folder.

1. Go to your repository's **Settings** tab.
2. In the left sidebar, click on **Pages**.
3. Under **Build and deployment**, for the **Source**, select **Deploy from a branch**.
4. Under **Branch**, select `main` and `/docs`.
5. Click **Save**.

Your presentation will be available at: https://21f3002378.github.io/week8/
